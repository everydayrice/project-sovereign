## Frozen decisions

- The platform has exactly four first-class modules: **COMMAND**, **INTELLIGENCE**, **CONTROL PLANE**, and **CONTINUITY**.
- **PROTOCOL** is the vendor-neutral lifecycle/compatibility contract, not a fifth module.
- Gateway, Console, Extension Host, Security, Sync, Efficiency, and Observability are interfaces or cross-cutting capabilities, not peer truth systems.
- RICE is tenant one and an alpha migration source. No core schema, API, or resource locator is RICE-specific.
- Canonical Intelligence and explicitly non-canonical Continuity remain distinct. Promotion is governed, attributable, and provenance-preserving.
- Control Plane is an orientation, routing, and traffic-coordination service. It must not silently impose a platform-selected minimum-context bundle. Authorized actors choose their context appetite and retrieval depth.
- Provider/model/account identity never substitutes for an independently operating **Actor Instance**. Multiple simultaneous chats on one provider are separate actors.
- Traffic uses renewable leases. A missing actor becomes `stale`; it is never inferred to be complete and cannot permanently lock a resource.
- Claims are narrow, scoped coordination metadata—not global repository locks. Command policy determines shared, cautionary, approval-gated, or exclusive behavior.
- Core remains fully useful with no extensions. Extensions receive only declared, tenant-granted scopes; first-party extensions have no hidden privilege.
- Queue Tracker, Idea Tracker, Workforce, and Compute are external products/extensions, not V0.2 core modules.
- Project Sovereign gets dedicated Worker, Neon, R2, and Auth infrastructure. It must not use RICE Lightning or RICE Command infrastructure as its core runtime.

## Material inconsistency resolved

`docs/NAMING.md` previously said that CONTROL PLANE resolves “how much context should be loaded, and what should be excluded.” That contradicts the approved agent-directed context model in `ARCHITECTURE`, `V1`, and `CONTROL-PLANE`.

V0.2 corrects the wording: Control Plane returns orientation, authority, traffic, and routes; the authorized actor chooses context appetite and retrieval. Hard permission, privacy, tenant, resource, and service-reliability boundaries remain enforced.

## Implementation boundary

This freeze does not claim a deployed runtime or a completed RICE migration. V0.2 starts with a provider-neutral, tested Control Plane vertical slice and persistence contracts. The dedicated infrastructure and Neon Auth connection remain explicit activation work.
