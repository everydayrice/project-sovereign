# Project Sovereign V1

## Objective

Ship a complete internal alpha of Sovereign core for one real tenant (RICE) without hard-coding RICE into the product model.

V1 must prove that a user can persist intelligence and continuity across AI providers, retrieve bounded authoritative context, inspect why that context was selected, and preserve material changes through governed promotion.

## Core platform only

V1 includes the four core modules:

- COMMAND
- INTELLIGENCE
- CONTROL PLANE
- CONTINUITY

It also includes the Protocol, Gateway, Console, Security, Sync, Efficiency telemetry and Extension Host required to operate those modules.

V1 does **not** include Queue Tracker, Idea Tracker, Workforce or Compute as built-in core products. Those are external extensions/add-ons.

## Infrastructure

Project Sovereign owns its own independent infrastructure:

- GitHub repository: `everydayrice/project-sovereign`
- Cloudflare Worker: dedicated Project Sovereign runtime
- Neon project: dedicated Project Sovereign database
- Cloudflare R2 bucket: dedicated Project Sovereign object/source storage
- Neon Auth for authentication

RICE is the first tenant and alpha tester.

## COMMAND V1

- tenant/workspace profile;
- user identity, roles and permissions;
- tenant policy and approval registry;
- authority/source configuration;
- model/agent/tool registry;
- integration registry;
- extension installation, scopes and revocation;
- privacy/retention configuration;
- audit browser;
- tenant branding/personalization, including presenting COMMAND as RICE COMMAND for the RICE tenant.

## INTELLIGENCE V1

- typed canonical records;
- facts, decisions, policies, architecture, projects/entities/domains and relationships;
- source registry and provenance;
- revision/supersession history;
- candidate-to-canonical promotion workflow;
- scoped canonical search/retrieval;
- tenant data export;
- preserved provenance when importing from existing RICE Command.

## CONTINUITY V1

- Session Capsules;
- Task Capsules;
- checkpoints;
- next actions/blockers/waiting state;
- candidate memories;
- Idea primitive/lifecycle objects;
- handoffs/resume packets;
- basic administrative inspection APIs/UI;
- explicit non-canonical semantics unless promoted.

Sovereign core intentionally does not ship a full Queue Tracker or Idea Tracker. RICE Lightning will provide those as alpha extensions using the same public extension contracts available to other publishers.

- task/scope classification;
- tenant policy enforcement;
- authority resolution;
- relevant Intelligence selection;
- relevant Continuity selection;
- context depth and budget controls;
- context packets with inclusion/exclusion reasons;
- freshness/live-source requirements;
- deterministic context revision/hash;
- contract support for known-context/delta delivery;
- model/agent/tool route recommendation;
- execution trace metadata.

## Protocol V1

Define a versioned vendor-neutral contract covering:

- tenant and actor identity;
- scope/task classification;
- authority/provenance;
- Intelligence vs Continuity boundaries;
- context packets;
- candidate promotion;
- verification/checkpoint/recovery lifecycle;
- permissions;
- extension compatibility;
- auditability.

## Gateway V1

- HTTP/JSON API;
- MCP server over the same internal operations;
- scoped service identities/API credentials;
- provider-neutral schemas;
- read APIs for Command, Intelligence, Continuity and Control Plane;
- governed Continuity writes;
- canonical proposal/promotion workflow;
- events/webhooks needed by extensions.

## Extension Host V1

- versioned extension manifest schema;
- manual/private extension installation;
- requested-scope review and approval;
- scoped extension identities;
- event subscriptions;
- external application launch metadata;
- revocation/uninstall;
- audit logging.

No public marketplace is required for V1.

First alpha extension target: `RICE Lightning / Queue Tracker`.

## Console V1

One human-facing shell:

- Home
- Command
- Intelligence
- Control Plane
- Continuity
- Extensions
- Integrations
- Audit / Health

The Console may show basic Continuity object inspectors, but specialized workflow UIs remain extensions.

## Efficiency V1

Measure rather than merely claim efficiency:

- context bytes/tokens considered;
- context bytes/tokens sent;
- duplicate context suppressed;
- unchanged context skipped;
- cache hits;
- retrieval depth;
- route recommendation/selection;
- retries/escalations;
- estimated model-input cost saved where pricing is known;
- request latency where available.

Efficiency remains a cross-cutting capability, not a module.

## RICE alpha migration

Build an explicit migration/import adapter from `everydayrice/rice-command`.

The migration must:

1. preserve repository/path/commit provenance;
2. distinguish canonical records from working/task/session state;
3. preserve source authority metadata;
4. avoid blindly copying obsolete/superseded records as current;
5. map RICE-specific identifiers through tenant-scoped configuration;
6. allow validation before final promotion/import;
7. retain export/rollback paths;
8. never make existing RICE Command history disappear merely because Sovereign becomes the new operational platform.

## V1 success criteria

V1 is successful when:

1. RICE can authenticate as the first tenant and operate a personalized RICE COMMAND instance.
2. A supported AI agent can connect through MCP or HTTP and retrieve minimum-sufficient Sovereign context without knowing storage internals.
3. The same durable Intelligence is reusable across at least two distinct agent/provider surfaces.
4. Session/Task continuity can be resumed after the original AI session is gone.
5. Working state is never silently treated as canonical truth.
6. A material candidate can be proposed, reviewed/promoted according to Command policy, and read back with provenance/audit history.
7. The Control Plane explains what it included, excluded and why.
8. RICE Lightning Queue Tracker can install as an external extension and work through normal scoped APIs/events rather than hidden first-party access.
9. Revoking the Queue extension stops its access without damaging Sovereign core data.
10. Runtime indexes/caches can be rebuilt without losing canonical Intelligence or Continuity source state.
